# 实施记录：真实模型与本地陪伴核心

## 2026-10-27：助手工具与主动提醒

在原有本地对话核心上加入模型工具调用循环，支持网页搜索、本地笔记、本地日历、一次性提醒、一次性跟进和每日主动关心。所有笔记、日程和任务按用户隔离；用户确认删除全部数据时一并删除。不保存模式下停止读取和写入这些本地内容，已有提醒暂停进入收件箱。

| 能力 | 本次实现与边界 |
| --- | --- |
| 模型工具调用 | DeepSeek / OpenAI 兼容 Chat Completions 工具调用；默认最多 5 轮，每次模型请求计入原有每日限制；已执行操作附回执，后续模型失败时仍说明实际执行结果 |
| 网页搜索 | 默认使用 DeepSeek Search，配置 Brave 密钥时使用 Brave；每日独立搜索次数限制；查询发送给对应供应商，可能单独计费 |
| 本地笔记 | 创建、搜索、读取和删除；内容保存在本地 SQLite，直到用户删除 |
| 本地日历 | 创建、查询、删除；按配置的固定 UTC 偏移解释本地时间，可提前创建提醒；不与外部日历同步 |
| 一次性提醒与跟进 | 本地持久化，到期后进入收件箱；单次事务避免重复入箱；进程重启后处理已到期任务 |
| 每日主动关心 | 默认关闭，用户设定本地时间后每天最多一条固定问候；仅在时间点后 5 分钟内且最近一小时无用户消息时发送，关闭时取消未读问候和待发一次性跟进 |
| 交付 | 网页每 5 秒刷新本地收件箱，可选浏览器通知；运行中的终端打印后标记已读。服务或浏览器关闭时不会即时通知，重启后处理待发提醒 |

使用临时数据库和合成输入，已通过真实 DeepSeek 调用验证网页搜索、创建笔记、创建日程及提前提醒、创建一次性提醒和开启每日主动关心。首次主动关心测试发现模型直接声称成功但未调用工具；现对明确的每日开关请求强制调用工具，并在回复中检查成功声明，修正后实测确认设置已写入。相关接口参考 [DeepSeek 工具调用](https://api-docs.deepseek.com/guides/tool_calls/)、[DeepSeek 搜索](https://api-docs.deepseek.com/guides/search/) 和 [Brave 搜索](https://api-dashboard.search.brave.com/app/documentation/web-search)。

完整自动化回归 46 项通过，覆盖工具循环与额度、用户隔离、不保存、提醒跨重启恢复、取消、每日跟进时间窗口、HTTP 接口及网页登录。随后对后台处理补充了失败后重试保护，并重跑网页与 API 测试。另在临时演示服务的浏览器页面中创建合成笔记和提醒，观察到提醒到期后自动进入收件箱；浏览器操作系统通知权限未实际授权测试。测试未读取或修改真实用户对话。

浏览器通知依赖浏览器与系统的通知权限，内容默认不放入系统通知；飞书、微信和外部日历同步尚未接入。服务仍为单实例本地原型；基础输出检查不是完整安全分类器。旧版网页服务需重启后才会加载新代码。

以下保留 2026-10-25 的原始实施记录；其中当时的未完成项以本节更新为准。

日期：2026-10-25。实施者：Codex；产品定位、云服务与试用准入仍由项目维护人决定。

依据：[计划 v2](emotional-agent-research-and-plan.md)、[复审建议](emotional-agent-revision-proposal.md)。第一轮只完成演示入口；根据用户继续落实可用陪伴 Agent 的要求，本轮接通真实模型，并补充不依赖网页的终端入口。原始计划保留作为目标，不把本地原型等同于完成全部 MVP。

## 本轮决策

| 决策 | 采用方式与依据 | 状态或未决事项 |
| --- | --- | --- |
| 本地入口 | 浏览器文字界面与 `--terminal` 终端入口，复用同一个核心 | 同一数据库只运行一个实例；没有声称飞书验证失败 |
| 界面与登录 | 复用 Gradio 5.45.0 组件、认证与队列 | 本轮使用本机已有版本；公开部署前重新核查安全更新 |
| 服务与存储 | FastAPI 0.121.3、Python 3.12.4、标准库 SQLite | 单进程、单事件循环；默认只监听 127.0.0.1 |
| 模型层 | 官方 OpenAI SDK 1.109.1 接入 DeepSeek `deepseek-flash` | 环境密钥验证成功且真实调用完成；密钥未写入项目文件；模型为供应商 ID，未锁底层权重快照 |
| 模型配置 | 本机 `.env` 指向已验证的 DeepSeek；支持显式 OpenAI 兼容配置 | `--demo` 才启用固定回复；没有凭证时报错，不伪装可用；不在故障时跨供应商切换 |
| 通用框架 | 本轮未安装 OpenClaw 或其他 Agent 框架 | 不需要多渠道、工具循环和自动记忆；渠道阶段再做限时接入实验 |
| 原文与偏好 | 原文 7 天，独立偏好凭据 14 天，均可提前删除 | 原文到期不撤回独立确认偏好；偏好期限是原型参数 |
| 不保存 | 原文与任务内容仅在内存，持久化无原文的模式/请求状态 | 不读取已有偏好用于生成；不能保证第三方零留存 |
| 自然语言控制 | 仅明确整句白名单命令；按钮提供确定入口 | 不宣称识别任意表达，不以关键词触发删除 |
| 预算 | 真实调用前原子预留每日次数；错误与取消不退回，响应返回实际 token 用量 | 尚无 token 单价/金额预算；开发样例使用独立库，每次最多 8 轮，独立于主服务次数统计 |
| 可靠性 | 单用户同时最多一轮，其他请求明确提示忙；最多 5 用户生成并发 | 不持久化任务原文，不自动重试或重放，不合并连发消息 |
| 保存与显示边界 | 完整输出后基础检查，再核验授权和数据版本；本地返回为交接点 | 本地返回不等于用户实际读到；没有渠道投递确认 |

## 当前交付

1. 本地账号登录 → 核心授权 → 生成 → 检查 → 提交与显示。
2. 未授权输入不进入模型、消息表或请求状态表。
3. 不保存样例不写本方持久内容；模式切换不补存此前消息。
4. 生成中停止、切换模式、撤回偏好和删除会使旧结果失效，包括取消后仍返回草稿的模拟适配器。
5. 明确确认后保存结构化偏好；查看、更正、撤回、过期和全部删除可执行。
6. 原文、偏好、请求元数据与内存上下文分别到期；不启用备份或恢复任务。
7. 模型故障显示具体的脱敏原因，区分认证、余额、限流、连接、超时及未完整生成；输入保留供重试，不用演示回复掩盖故障。控制功能不消耗模型额度。
8. 真实模型的模型名、输入/输出 token 和耗时随接口结果返回；合成开发样例另存版本与完整测试回复，真实用户对话不进入该报告。
9. 网页与终端均实际收到了真实模型回复，原有本地账号保留。网页仅是核心的一个接入界面。

## 验证边界

自动化测试结果以本轮运行记录为准，覆盖核心、HTTP 接口、官方 SDK 模拟传输和 Gradio 实际登录/回调。所有输入为合成数据；未向真实模型发送倾诉内容。

第一轮结果：25 项通过；本轮新增配置选择、DeepSeek 参数、错误分类与脱敏及真实用量测试后，**34 项通过，耗时 53.71 秒**。现有全局 Python 环境有 3 条第三方告警（websockets 旧模块、pandas 可选的 numexpr/bottleneck 版本），不影响本轮测试。Windows 受限执行环境无法建立 asyncio 所需的本机 socketpair，因此测试在获准使用本机回环连接的环境中执行，并将临时数据限定到项目 `data/test-*` 目录。

## 真实模型开发记录

使用现有 `DEEPSEEK_API_KEY`，先在官方 `/models` 接口核验 `deepseek-flash` 可访问，再通过官方 SDK 实际生成。DeepSeek 文档中思考模式默认开启，本项目显式关闭以适应短回复；没有向该供应商发送未列出的 `store` 参数。

- [初次开发检查](evaluations/model-smoke-820f9216.json)：8 轮完成，发现拒绝建议后仍会以“早点歇”收尾。
- [提示词修订后检查](evaluations/model-smoke-dc9b041e.json)：8 轮完成，补充“休息、喝水也属于建议”和资料不足的表达规则。
- [一次中止记录](evaluations/model-smoke-ed60d4a1.json)：第一轮出现连接故障后停止，保留失败证据，没有重试或切换模型。随后非计费模型列表检查及独立网页请求恢复成功。
- [最终开发检查](evaluations/model-smoke-71a052d2.json)：8 轮完成，提示词 `2026-10-25.real-v2`，这次换话题测试保留此前倾诉上下文。共 3,101 输入 token、124 输出 token；单轮 891–1,577 毫秒，仅代表该次单用户开发运行。

末轮观察：连续拒绝建议后没有追加行动清单，要求少说且别提问后返回简短陈述；能转向普通话题；已确认称呼在新会话中可用，不保存及撤回后不再引用。仍有样式问题：“不知道就直接说不知道”之后会追加称呼询问。这些是同一开发集上的观察，不能视作正式体验通过或优于基线的证据。

另外，分别通过终端及正在运行的 Gradio 认证接口实际发送短合成消息，收到“终端连接成功”“网页模型连接成功”。主服务健康接口返回 `provider=deepseek`、`model=deepseek-flash`、`real_model=true`，不是演示回复开关。

没有运行 20 场多模型初筛、60–100 场独立对话验收或人工盲评，没有完成多用户真实准入、P95 延迟、平台投递、灾备恢复或正式风险响应验证。不能把少量本地规则、开发回复和自动化工程测试解释为陪伴效果或现实安全性已经达标。

下一步优先扩展独立合成场景、确认供应商数据条款与实际金额预算，再开展飞书账号准入和 SDK/框架限时实验。正式邀请用户前补足全部关键验收，不能仅凭当前原型扩大试用。
