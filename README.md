# Serein

中文本地文字助手，支持情绪陪伴、多轮对话、可控偏好记忆，以及网页搜索、本地笔记、日程、提醒和主动跟进。支持真实 DeepSeek / OpenAI 兼容模型，以及网页、终端两种本地入口；两种入口共用同一个核心。原始情感陪伴目标见[实施计划](docs/emotional-agent-research-and-plan.md)。

可通过环境变量配置 DeepSeek 密钥。固定回复只在显式演示模式中启用；真实服务失败时不会偷偷切回演示回复。

## 启动

Python 3.11 或以上。在项目目录执行：

```powershell
python -m venv .venv
.\.venv\Scripts\python -m pip install -e ".[test]"
Copy-Item .env.example .env
# 在系统环境或 .env 中配置 DEEPSEEK_API_KEY；已有环境密钥可直接复用。
.\.venv\Scripts\python -m serein
```

打开 [本地聊天入口](http://127.0.0.1:7860/chat/)，使用终端显示的 `local` 账号和随机密码登录。配置 `SEREIN_USERS` 后使用配置中的账号。默认仅监听本机；单进程运行。端口被占用时使用 `python -m serein --port 7861`。

依赖已安装时，可直接执行 `python -m serein`。项目锁定了本轮实测的直接依赖版本；这是本地实验基线，公开部署前需要单独复核依赖和安全更新。

也可以直接在终端聊天：

```powershell
python -m serein --terminal
```

终端通过本机权限使用 `local`（不存在时使用第一个配置账号），支持 `/new`、`/private on`、`/private off`、`/memory`、`/exit`。终端不需要启动网页或 Gradio。当前是单进程原型，请先停止网页服务，再用同一数据库启动终端；不要并行启动多个服务实例。

没有密钥时，可以显式使用 `python -m serein --demo` 或 `python -m serein --terminal --demo` 测试固定回复。未配置模型时普通启动会明确报错，不会伪装成模型可用。

## 可以试什么

- 文字聊天与最近 20 条、最多约 12,000 字符的上下文；完整生成并做基础检查后显示。
- 不保存模式：不持久化原文、不自动读取或修改已有偏好，切换后清空当前上下文。
- 在表单里确认称呼、回复长短、倾听方式；查看确认凭据、更正或撤回偏好。
- 停止生成、开始新对话、确认后删除本方全部对话和偏好。
- 白名单账号隔离、请求 ID 去重、超时退路、全局每日调用次数限制。
- 真实模型可调用网页搜索、本地笔记、本地日历、一次性提醒与跟进工具；支持在聊天中创建、查询和取消。
- 网页提供搜索、笔记、日程、提醒和每日主动关心设置；未读提醒在页面中自动刷新，也可由用户授权浏览器弹出不含内容的通知。
- 终端运行期间会显示到期提醒；服务停止期间到期的提醒会在下次启动后进入本地收件箱。

先使用界面提供的合成场景，例如“今天被领导批评了，我觉得自己特别没用”。真实模型按最近上下文与获准读取的偏好生成内容；**演示模式的少量规则回复仅验证流程，不代表模型能力。**

真实模型的人格与对话规则位于 [`serein/prompts.py`](serein/prompts.py)，角色方向、试聊场景及未来知识库接入边界见[人格提示词说明](docs/personality-prompt.md)。修改提示词后需重启服务。

工具调用可试这些合成示例：

- “搜索 Python 官方网站，并告诉我链接。”
- “创建一条笔记，标题是项目想法，内容是做一个个人助手。”
- “明天上午九点创建一个面试日程，提前十分钟提醒我。”
- “明晚八点问我面试怎么样。”
- “开启每天晚上八点的主动关心。”或在网页中自行设置、关闭。

每日主动关心默认关闭，启用后在指定本地时间每天最多生成一条简短问候；服务在指定时间的五分钟内未运行，或用户在过去一小时刚发过消息时，当天不补发。一次性跟进保存的是用户要求询问的内容。关闭主动关心会取消尚未送达的一次性跟进和未读主动关心。提醒及跟进存放在本地，不会自动发送到微信或飞书。

服务需要保持运行才能按时处理；网页通知还需要浏览器保持打开并同意通知权限。服务暂停时不承诺实时弹出，重启后会处理未取消的过期提醒。日历是本项目的本地日程，不会同步 Google 日历、飞书日历或系统日历。

默认采用 UTC+08:00；其他固定时区可通过 `SEREIN_TIMEZONE_OFFSET_MINUTES` 配置，例如 UTC+08:00 为 `480`。带时区的 ISO 8601 时间使用所指定的时区；没有时区的时间按上述本地偏移解释。

固定命令仅支持整句匹配：`查看记忆`、`停止当前回复`、`开启不保存`、`关闭不保存`，以及 `/memory`、`/stop`、`/private on`、`/private off`。其他自然语言交给聊天处理。引用、否定或假设中的控制词不会触发操作。保存、撤回与删除建议使用界面按钮。

## 配置真实模型

DeepSeek 配置如下，已有环境中的 `DEEPSEEK_API_KEY` 会被直接复用：

```dotenv
SEREIN_PROVIDER=deepseek
SEREIN_CLOUD_ACKNOWLEDGED=true
SEREIN_MODEL=deepseek-flash
# DEEPSEEK_API_KEY=your-api-key
```

`auto` 选择已明确配置的 OpenAI 模型或已有 DeepSeek 凭证；启动后供应商固定，不会在故障时跨供应商切换。其他 OpenAI 兼容服务可配置：

```dotenv
SEREIN_PROVIDER=openai
SEREIN_CLOUD_ACKNOWLEDGED=true
OPENAI_API_KEY=your-api-key
OPENAI_BASE_URL=https://api.openai.com/v1
SEREIN_MODEL=your-tested-model-id
```

使用官方 OpenAI Python SDK 的异步 Chat Completions 接口。OpenAI 配置发送 `store=false`；DeepSeek 按其文档关闭思考模式，不发送该服务未列出的 `store` 参数。其他兼容服务的实际参数支持需验证。SDK 自动重试关闭，超时默认 20 秒，输出上限默认 400 token。

密钥无效、余额不足、限流、连接失败、超时和不完整回复分别返回明确原因，保留输入以便重试。模型错误正文、密钥和可能包含原文的异常详情不显示给用户或写入业务日志。成功的接口结果包含模型名、实际输入/输出 token 数和耗时。

内容会发送至配置的模型服务，界面和终端会展示服务地址。首次连接和开发验证使用合成内容。`store=false` 只是部分服务的请求参数，不能代表供应商零留存。

可在 `.env` 设置固定白名单账号：

```dotenv
SEREIN_USERS={"local":"replace-with-a-long-random-password"}
```

每个密码至少 12 字符。不同账号隔离上下文和偏好；同一账号的标签页共享控制状态。配置变更需重启，不支持在线用户管理。凭证不要提交到仓库。

其余可选参数见 [.env.example](.env.example)。每日限额是全局模型调用次数，按 UTC 零点重置，失败、超时和取消也占用已预留次数；删除用户数据不会清零限额。**尚未实现按实际 token 单价结算的金额预算**，使用云模型时仍应配置供应商费用限额。

网页搜索在 DeepSeek 模式下默认使用现有 DeepSeek 密钥调用 [DeepSeek Search API](https://api-docs.deepseek.com/guides/search/)；如配置 `BRAVE_SEARCH_API_KEY`，则使用 [Brave Search API](https://api-dashboard.search.brave.com/app/documentation/web-search)。使用其他模型时需配置 Brave 密钥。搜索词会发送给对应搜索服务，搜索请求可能单独计费；`SEREIN_DAILY_SEARCH_LIMIT` 默认限制每天 25 次，失败请求也计入本项目的次数限制。

## 数据边界

| 项目 | 当前实现 |
| --- | --- |
| 普通对话 | 成功完成的一轮原文与回复保存至本机 SQLite，默认 7 天；失败或取消的轮次不保存原文 |
| 上下文 | 仅进程内存，不从磁盘自动恢复；默认空闲 30 分钟清除，最长 2 小时，进程关闭即丢失 |
| 不保存 | 原文只用于运行中任务和当前内存上下文；不写数据库、示例缓存或业务日志；重启不恢复 |
| 确认偏好 | 默认 14 天；只保存三项偏好、版本、确认时间和随机操作 ID，不复制倾诉原文 |
| 请求元数据 | 用户作用域、随机请求 ID、状态，默认 24 小时，不含原文；到期后不保证去重 |
| 保存模式 | 独立保留到账号不再使用；删除对话不会擅自关闭不保存模式 |
| 调用计数 | 按日的全局次数，不含内容或用户 ID，最多 7 天 |
| 笔记、日程、待发提醒 | 本地 SQLite 按用户隔离保存，直到删除或取消；关闭应用不会自动清除 |
| 提醒与跟进收件箱 | 用户在网页中确认已读，或终端打印后标记已读；已读记录最多保留 7 天 |
| 清理 | 启动、聊天时及每 30 秒清理到期记录；偏好查询本身也排除到期项 |
| 备份 | 不创建备份、不恢复历史任务；备份恢复治理尚未实现，请勿用旧库恢复后开展试用 |

原文到期不会撤回独立确认的偏好；撤回偏好会清空当前上下文，避免旧偏好继续影响生成。更正会产生新版本。普通模式历史不会自动重新加载到新会话。

不保存模式下禁止读取或新增本地笔记、日程和提醒，也不能开启主动跟进；此前建立的提醒暂停进入收件箱，关闭不保存模式后恢复处理。删除全部数据会同时删除笔记、日程、提醒、收件箱和主动跟进设置；全局调用计数保留。

删除、模式切换或停止在同一事件循环内失效旧任务；生成结束后重新检查授权和版本。最后检查、数据库提交及结果返回之间不插入异步等待，以结果返回给本地界面/HTTP 层为交接边界；已交接的回复无法保证撤回。

界面复用 Gradio，关闭遥测、示例缓存、文件输入和自动浏览器历史保存，文本通过运行中的事件队列传递。本方不保存不等于浏览器、操作系统或云供应商零留存；页面已显示的内容也不会因服务端空闲清理自动消失。SQLite 使用 `secure_delete`，但不承诺磁盘取证层面的物理擦除。

## API 与测试

交互式接口说明：[本地 API 文档](http://127.0.0.1:7860/docs)。`/api/*` 使用相同白名单账号的 HTTP Basic 鉴权，界面使用 Gradio 内置登录。`/health` 仅返回无内容的服务状态。

```powershell
python -m pytest
```

自动化测试覆盖授权隔离、不保存、取消、偏好与数据删除、工具调用、提醒恢复、主动跟进、供应商参数及界面回调。SDK 测试使用 MockTransport，不调用收费模型。最新运行结果见[实施状态](docs/implementation-status.md)。

另外可显式运行真实模型开发样例：

```powershell
python -m serein.evaluate
```

每次最多 8 个短合成轮次，用独立临时库隔离真实对话，验证连续拒绝建议、要求少说、上下文中换话题、未知事实、确认偏好、禁读与撤回。输出保存至 `docs/evaluations/`，包含版本、模型、token、耗时和合成回复；开发样例调用单独计数，不计入主应用数据库的每日限额。它是可重跑的开发检查，不是独立盲评或正式安全验收。

## 复用与实施状态

沿用 Python + FastAPI + SQLite，使用 [Gradio 的 FastAPI 挂载能力](https://gradio.app/docs/gradio/mount_gradio_app)复用聊天组件、登录和事件队列，模型请求使用[官方 OpenAI Python SDK](https://developers.openai.com/api/reference/python)。DeepSeek 适配依据[官方接入示例](https://api-docs.deepseek.com/)及[接口参数](https://api-docs.deepseek.com/api/create-chat-completion/)，并已实际调用验证。SQLite、数据版本和用户控制是本项目需要实现的业务部分；当前无需引入通用 Agent 框架、向量库或多 Agent 编排。

详见[决策与验收记录](docs/implementation-status.md)。当前支持的提醒交付范围是本地网页、可选浏览器通知与运行中的终端；飞书、微信接入、金额预算、完整风险响应验收、正式盲评和备份恢复仍待完成。当前基础输出规则只拦截少数明显问题，**不构成完整安全分类器或正式试用验收**。
